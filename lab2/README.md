# Connect 4 AI Engine: Adversarial Search

## Overview
This laboratory involves the development of an intelligent game-playing agent capable of playing Connect 4 at a highly competitive level using adversarial search techniques.

## Objectives
- Implement the Minimax algorithm to evaluate game states and predict opponent moves.
- Integrate Alpha-Beta Pruning to optimize the search tree and significantly reduce computation time.
- Develop advanced evaluation heuristics to accurately score board configurations.
- Provide real-time visualization of the AI's principal variation decision tree.

## Technical Details
- **Language**: Python
- **Algorithms**: Minimax, Alpha-Beta Pruning
- **Concepts**: Adversarial Search, Heuristic Evaluation, Game Theory
