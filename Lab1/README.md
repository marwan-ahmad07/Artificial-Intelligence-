# Artificial Intelligence: Search Algorithms

## Overview
This laboratory introduces fundamental artificial intelligence search strategies, exploring how intelligent agents navigate state spaces to reach goal configurations.

## Objectives
- Implement foundational uninformed and informed search algorithms.
- Analyze the time and space complexity of different search methodologies.
- Apply search algorithms to solve deterministic pathfinding problems.

## Technical Details
- **Language**: Python
- **Focus Area**: State Space Search, Pathfinding, Algorithmic Efficiency
