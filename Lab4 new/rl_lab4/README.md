Assignment 4 — Gridworld Value & Policy Iteration

Run the scripts with Python 3.8+.

Install requirements:

```bash
pip install -r rl_lab4/requirements.txt
```

Run the main driver to compute policies for each (R1,R2) pair:

```bash
python3 rl_lab4/main.py
```

Run the GUI (Tkinter):

```bash
python3 rl_lab4/gui.py
```

Run tests:

```bash
pytest -q
```
