# Sudoku CSP AI Solver

## Overview
This laboratory focuses on Constraint Satisfaction Problems (CSP) by engineering an intelligent agent capable of solving complex Sudoku puzzles.

## Objectives
- Formulate the Sudoku game as a formal Constraint Satisfaction Problem.
- Implement Backtracking search algorithms to explore potential variable assignments.
- Integrate advanced constraint propagation techniques, specifically Arc Consistency (AC-3/MAC), to drastically reduce the search space.
- Benchmark solver performance across varying puzzle difficulties.

## Technical Details
- **Language**: Python
- **Algorithms**: Backtracking Search, AC-3 (Arc Consistency)
- **Focus Area**: Constraint Satisfaction, Constraint Propagation, State Space Reduction
